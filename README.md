# 🎬 IMDb Movie Review Sentiment Analysis AI

An interactive Web Application for IMDb movie review sentiment analysis with **Explainable AI (XAI)** built using Python and Streamlit.

## ✨ Features
- 🚀 **Multiple ML Models**: Compare predictions across Logistic Regression, Naive Bayes, SVM, Random Forest, Gradient Boosting, and XGBoost.
- 🎯 **Confidence Scores**: Real-time confidence probabilities for Positive/Negative predictions.
- 🔍 **Explainable AI (XAI)**: Identifies influential keywords driving positive or negative sentiment via perturbation analysis.
- 🎨 **Modern Dark Glassmorphic UI**: High-contrast, responsive interface.

## 🛠️ Tech Stack
- **Python 3.7+**
- **Streamlit** (Web Interface)
- **Scikit-Learn & XGBoost** (Machine Learning Pipeline)
- **NLTK & TF-IDF Vectorizer** (Text Preprocessing & Feature Extraction)
